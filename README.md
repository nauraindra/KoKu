# KoKu - Modern Kost Management System

KoKu adalah aplikasi web dinamis berbasis Laravel untuk membantu pengelolaan kos atau kost secara modern. Aplikasi ini memiliki dua role utama, yaitu admin dan penyewa.

## Fitur Utama

### Admin
- Login dan logout berbasis session.
- Dashboard statistik.
- Manajemen data penyewa.
- Manajemen data kamar.
- Upload foto kamar.
- Detail kamar.
- Riwayat transaksi pembayaran.
- Verifikasi pembayaran penyewa.
- Penolakan pembayaran.
- Live search penyewa menggunakan Fetch API dan JSON.
- Preferensi tampilan light mode dan dark mode.

### Penyewa
- Register akun penyewa.
- Login dan logout.
- Dashboard penyewa.
- Melihat daftar kamar.
- Melihat detail kamar.
- Booking kamar.
- Melihat riwayat pembayaran.
- Mengirim pembayaran dan upload bukti pembayaran.
- Mengedit profil, nomor HP, alamat, dan foto profil.
- Weather card berbasis Fetch API.
